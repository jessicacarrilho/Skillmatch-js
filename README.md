## Sobre o Projeto:
O Skillmatch JS é um simulador simples de compatibilidade entre um candidato e vagas de front-end júnior.
O projeto compara as habilidades, calcula o percentual de compatibilidade com cada vaga e sugere o que estudar para aumentar as chances de aprovação.
Ele mostra:

- percentual de compatibilidade;
- habilidades encontradas;
- habilidades faltantes;
- vaga mais compatível;
- recomendação de estudo.

## Como executar
Este projeto não precisa de Node.js.
Você pode executar de uma destas formas:
1. Abrir o navegador Google Chrome.
2. Pressionar F12 ou Ctrl + Shift + J.
3. Abrir a aba Console.
4. Copiar o código do arquivo skillmatch.js.
5. Colar no console.
6. Pressionar Enter.

## Como foram usados os conceitos de JavaScript
Objeto = Perfil da candidata (candidato)
Array = Lista de vagas disponíveis
Tipos de dados = Strings, números, arrays e booleanos
If-else = Classificação de compatibilidade (Alta/Média/Baixa)
Operadores lógicos e matemáticos = Cálculo do percentual de compatibilidade
let e const = Declaração de variáveis 
Funções = Separação das responsabilidades do sistema
Arrow functions = Usadas nos métodos de array
map = Geração da lista de vagas com compatibilidade calculada
filter = Separação de habilidades encontradas e faltantes
includes = verificação se a candidata possui cada habilidade exigida pela vaga
Classes = Classe Vaga com atributos e métodos
Construtor = constructor na classe Vaga
Herança = Classe SugestaoEstudo que herda de Vaga
this = Usado nos métodos da classe Vaga
callback = Função finalizarAnalise recebe exibirMensagemFinal como parâmetro para exibir a mensagem final
Closure = Função criarCandidato protege as habilidades da candidata
Promise = Simulação de carregamento assíncrono das vagas
async/await = Função iniciarSistema aguarda cada etapa antes de continuar
setTimeout = Contador de segundos durante a busca de vagas
